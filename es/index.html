Calculadora de radio de Schwarzschild

Calcule el radio del horizonte de un modelo de agujero negro no giratorio y sin carga. Elija unidades de entrada y calcule un valor dentro de las condiciones establecidas.

Datos de entrada

Mayor que cero tras convertir a SI

Puede usar punto o coma decimal. No use separadores de miles. Los cálculos se realizan en este navegador. Se admite notación científica, por ejemplo 1.2e-3. No use separadores de miles.

Resultado

Radio de Schwarzschild r_s

Introduzca los valores y pulse Calcular.

FÓRMULA

r_s = 2GM/c²

Condiciones de aplicación

Requerido: M>0. Este es el radio del horizonte de Schwarzschild no giratorio y sin carga. Excluidos: giro, carga, discos y tamaño de sombra aparente. El resultado no clasifica un objeto observado como un agujero negro.

Los valores mostrados son aproximaciones de coma flotante. No se calculan los factores de seguridad de diseño ni las contribuciones de error no introducidas.
